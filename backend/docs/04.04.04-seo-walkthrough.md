## 1. Việc Đã Làm

### A. Backend SEO Foundation (Step 4.4.1)
- Xây dựng **Sitemap Generator** set-based query với Drizzle ORM (tối đa 8 queries để hydrate toàn bộ CSDL du lịch Hoàng Su Phì mà không bị N+1).
- Thiết lập **Robots.txt Builder** tự động phát hiện môi trường `NODE_ENV` để `Disallow: /` trên Staging/Dev và cho phép index trên Production.
- Cấu hình **Local Cache & ETag layer** trên Hono:
  - Cache hits trả về `304 Not Modified` ngay lập tức mà không truy cập Database.
  - Phản hồi Warm cache hit p95 đạt **0.0196 ms**.
  - Áp dụng cơ chế **fail-closed**: Nếu cache hết hạn và DB sập, trả về `503 Service Unavailable` để bảo vệ tính đồng bộ.
- Viết bộ kiểm thử PostgreSQL integration suite và benchmark cold/warm.

### B. Frontend Rendering & Structured Data (Step 4.4.2)
- Khởi tạo minimal Next.js 15 App Router SEO shell tại `/frontend`.
- Thiết lập environment validator fail-fast cho `PUBLIC_SITE_URL`.
- Viết helpers xây dựng Metadata động (canonical links, og:url, og:type, og:locale `vi_VN`) và **secure JSON-LD serializer** mã hóa Unicode hex (`\u003c`, `\u003e`, `\u0026`) chống script injection & XSS.
- Implement visual và JSON-LD Breadcrumbs cho 10 MVP route templates.
- Trích xuất `{ data: projection }` đúng dạng response envelope.

### C. Integration Audit & Phase Lock (Step 4.4.3)
- Fix triệt để các lỗi `any` casting, non-null assertions (`!`), và unused variables trong `seo.controller.ts`, `seo.service.ts`, `container.ts` và benchmark script.
- Tổ chức lại Next.js test pipeline: tách biệt pure unit tests (`bun run test`) và SSR HTML runtime smoke tests (`bun run test:runtime` dựng mock server).
- Đồng bộ thông tin session history, roadmap và project context.
