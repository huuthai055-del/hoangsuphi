# Phase 4.8.1 — Harvest Foundation & Admin Lifecycle Implementation

## Goal
Tạo nền tảng cho module Harvest Status (Cập nhật mùa lúa), bao gồm schema cơ sở dữ liệu, quản lý lifecycle và API quản trị (CRUD). Hỗ trợ xác minh và gắn Media theo owner `HARVEST_UPDATE`.

## Completed Work
1. **Schema & Database Migrations**
   - Tạo schema `harvest_updates` với UUID v7, stage, status, observedAt, và nullable advisory.
   - Sinh migration `0019` và áp dụng thành công.
2. **Permissions**
   - Bổ sung quyền `harvest:write` vào danh sách hệ thống (`seed.ts`).
   - Cấp quyền tự động cho Editor Role và Admin.
3. **Media Ownership & Integration**
   - Phát triển `HarvestMediaOwnershipAdapter` (`ports/media-ownership.adapter.ts`).
   - Xác minh media hợp lệ (IMAGE, READY, not deleted, same uploader) trước khi gán ownership atomically.
4. **Service & Repository Layer**
   - Hỗ trợ PostgreSQL transactions đầy đủ (`Drizzle ORM`).
   - Kiểm tra Region level 3/4 (Chỉ hỗ trợ cấp Xã/Bản).
   - Validate logic vòng đời chặt chẽ (DRAFT -> PUBLISHED -> ARCHIVED).
5. **Controllers & Routing**
   - Cấu hình 4 endpoints Admin API bảo mật với JWT và zod validation.
6. **Integration Tests**
   - Viết bài test tích hợp PostgresSQL với Bun để xác thực luồng tạo mới, sửa chữa, thay đổi trạng thái và gắn kết dữ liệu.

## API Documentation
| Method | Route | Description | Permission |
| --- | --- | --- | --- |
| `POST` | `/api/v1/admin/harvest-status` | Tạo bản nháp (DRAFT) | `harvest:write` |
| `PATCH` | `/api/v1/admin/harvest-status/:id` | Cập nhật bản nháp (DRAFT) | `harvest:write` |
| `POST` | `/api/v1/admin/harvest-status/:id/publish` | Công khai bài đăng (PUBLISHED) | `harvest:write` |
| `POST` | `/api/v1/admin/harvest-status/:id/archive` | Lưu trữ bài đăng (ARCHIVED) | `harvest:write` |

## Notes
- Media detachment qua `PATCH` hiện bị block một phần ở level Adapter để tuân thủ kiến trúc Phase 4.3 (không có hàm detach an toàn), tuy nhiên hỗ trợ add/append thêm ảnh nếu cần (tối đa 8 ảnh).
- Việc publish tự động gắn `publishedAt` cho record.
