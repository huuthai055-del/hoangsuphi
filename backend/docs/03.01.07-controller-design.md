## 1. MỤC TIÊU

Thiết kế chi tiết tầng giao tiếp API (Presentation/Controller Layer) cho **Identity Module** nhằm:
- Hiện thực hóa các API endpoints đã được phê duyệt tại `03.01.02` sử dụng framework Hono.js.
- Thực thi đúng quy trình xử lý request chuẩn hóa toàn dự án:
  `Request` → `Validate (Zod)` → `Normalize` → `Controller` → `Service` → `Repository` → `Response`.
- Thiết lập cơ chế thiết lập Cookie bảo mật cao (`hsp_refresh_token`) trực tiếp tại Hono Controller.
- Cấu hình Router Guards: Tích hợp Middleware xác thực (`authenticate`) và Middleware kiểm tra quyền (`requirePermission`) để bảo vệ tài nguyên an toàn.
- Đảm bảo Controller mỏng (Thin Controller), chỉ nhận tham số -> chuyển tiếp xử lý -> định cấu hình Response, không chứa bất kỳ logic nghiệp vụ nào.

---

## 2. THIẾT KẾ & KIẾN TRÚC ROUTER - CONTROLLER FLOW

```
                       [HTTP Request]
                             │
                             ▼
                  [Zod Validation Middleware]
                             │  (Validate & Normalize)
                             ▼
                 [Router Middleware Guards] (authenticate & requirePermission)
                             │
                             ▼
                [AuthController / UsersController]
                             │  (Thin: Calls Service Layer)
                             ▼
                      [Service Layer]
```

### 2.1 Chi tiết Triển khai Controllers

#### 1. `AuthController`: `apps/backend/src/modules/auth/route/auth.controller.ts`

```typescript
import { Context } from 'hono'
import { AuthService } from '../service/auth.service'
import { LoginRequestDto } from '../dto/auth.dto'

export class AuthController {
  constructor(private readonly authService: AuthService) {}

  /**
   * Handler: POST /login
   */
  public login = async (c: Context) => {
    // 1. Nhận dữ liệu sạch đã được Validate & Normalize từ middleware
    const body = c.req.valid('json') as LoginRequestDto
    
    // 2. Thu thập Client Fingerprint từ headers/request
    const ipAddress = c.req.header('x-forwarded-for') || c.req.header('x-real-ip') || '127.0.0.1'
    const userAgent = c.req.header('user-agent') || 'unknown'

    // 3. Gọi Service Layer xử lý nghiệp vụ
    const result = await this.authService.login(body, { ipAddress, userAgent })

    // 4. Thiết lập Refresh Token bảo mật qua Cookie (Secure động theo môi trường)
    const isProd = process.env.NODE_ENV === 'production'
    const secureFlag = isProd ? 'Secure;' : ''
    c.header(
      'Set-Cookie',
      `hsp_refresh_token=${result.refreshToken}; Path=/api/v1/auth; HttpOnly; ${secureFlag} SameSite=Strict; Max-Age=2592000`
    )

    // 5. Trả response JSON theo định dạng chuẩn { data, meta }
    return c.json({
      data: {
        accessToken: result.accessToken,
        expiresIn: result.expiresIn,
        tokenType: 'Bearer'
      }
    }, 200)
  }

  /**
   * Handler: POST /refresh
   */
  public refresh = async (c: Context) => {
    // 1. Đọc Refresh Token trực tiếp từ HTTP Cookie
    const cookies = c.req.header('cookie') || ''
    const match = cookies.match(/hsp_refresh_token=([^;]+)/)
    const rawRefreshToken = match ? match[1] : null

    if (!rawRefreshToken) {
      return c.json({
        type: 'https://hoangsuphi.vn/errors/unauthenticated',
        title: 'Authentication Required',
        status: 401,
        code: 'AUTH_003',
        detail: 'Refresh token cookie is missing.'
      }, 401)
    }

    // 2. Gọi Service xử lý
    const result = await this.authService.refresh(rawRefreshToken)

    // 3. Trả về Access Token mới
    return c.json({
      data: {
        accessToken: result.accessToken,
        expiresIn: result.expiresIn,
        tokenType: 'Bearer'
      }
    }, 200)
  }

  /**
   * Handler: POST /logout
   */
  public logout = async (c: Context) => {
    // 1. Lấy thông tin session id được nạp từ Access Token của middleware authenticate
    const userContext = c.get('user') // Nạp bởi token validator middleware
    const sessionId = userContext?.sessionId

    if (sessionId) {
      // 2. Gọi Service thu hồi session
      await this.authService.logout(sessionId)
    }

    // 3. Xóa Cookie trên trình duyệt
    const isProd = process.env.NODE_ENV === 'production'
    const secureFlag = isProd ? 'Secure;' : ''
    c.header(
      'Set-Cookie',
      `hsp_refresh_token=; Path=/api/v1/auth; HttpOnly; ${secureFlag} SameSite=Strict; Max-Age=0`
    )


    return c.json({
      data: {
        success: true,
        message: 'Logged out successfully.'
      }
    }, 200)
  }
}
```

#### 2. `UsersController`: `apps/backend/src/modules/users/route/users.controller.ts`

```typescript
import { Context } from 'hono'
import { UsersService } from '../service/users.service'
import { UpdateProfileDto } from '../dto/users.dto'

export class UsersController {
  constructor(private readonly usersService: UsersService) {}

  /**
   * Handler: GET /users/me
   */
  public getMe = async (c: Context) => {
    const userContext = c.get('user') // Lấy thông tin user nạp từ Access Token
    
    const profile = await this.usersService.getProfile(userContext.sub)

    return c.json({
      data: profile
    }, 200)
  }

  /**
   * Handler: PATCH /users/me
   */
  public updateMe = async (c: Context) => {
    const userContext = c.get('user')
    const body = c.req.valid('json') as UpdateProfileDto

    const updatedProfile = await this.usersService.updateProfile(userContext.sub, body)

    return c.json({
      data: updatedProfile
    }, 200)
  }
}
```

### 2.2 Định cấu hình Hono Router & Guards

#### `apps/backend/src/modules/auth/route/auth.route.ts`
```typescript
import { Hono } from 'hono'
import { AuthController } from './auth.controller'
import { AuthService } from '../service/auth.service'
import { DrizzleUserRepository } from '@/modules/users/repository/users.repository'
import { DrizzleSessionRepository } from '../repository/session.repository'
import { TokenService } from '@/lib/auth/token.service' // Implement ITokenService
import { zValidator } from '@/common/middleware/validation.middleware'
import { LoginRequestSchema } from '../dto/auth.dto'
import { authenticate } from '@/common/middleware/auth.middleware' // Middleware xác thực Access Token

const authRoute = new Hono()

// Khởi tạo dependencies thủ công (hoặc qua Container DI)
const userRepo = new DrizzleUserRepository()
const sessionRepo = new DrizzleSessionRepository()
const tokenService = new TokenService()
const authService = new AuthService(userRepo, sessionRepo, tokenService)
const authController = new AuthController(authService)

// Định nghĩa routes
authRoute.post('/login', zValidator('json', LoginRequestSchema), authController.login)
authRoute.post('/refresh', authController.refresh)
authRoute.post('/logout', authenticate, authController.logout) // Cần access token để xác định session cần xóa

export { authRoute }
```

#### `apps/backend/src/modules/users/route/users.route.ts`
```typescript
import { Hono } from 'hono'
import { UsersController } from './users.controller'
import { UsersService } from '../service/users.service'
import { DrizzleUserRepository } from '../repository/users.repository'
import { zValidator } from '@/common/middleware/validation.middleware'
import { UpdateProfileSchema } from '../dto/users.dto'
import { authenticate } from '@/common/middleware/auth.middleware'
import { requirePermission } from '@/common/middleware/rbac.middleware'

const usersRoute = new Hono()

const userRepo = new DrizzleUserRepository()
const usersService = new UsersService(userRepo)
const usersController = new UsersController(usersService)

// Bảo vệ toàn bộ endpoint /users/me
usersRoute.get('/me', authenticate, requirePermission('user:read'), usersController.getMe)
usersRoute.patch('/me', authenticate, requirePermission('user:write'), zValidator('json', UpdateProfileSchema), usersController.updateMe)

export { usersRoute }
```

## 3. DEPENDENCY & LUỒNG TUÂN THỦ QUY TRÌNH CHUẨN

Ghi nhận luồng xử lý gói gọn cho endpoint `PATCH /api/v1/users/me`:

1. **Request:** Client gửi PATCH `/api/v1/users/me` kèm body `{ "firstName": "Hoàng", "bio": "Lúa chín Bản Phùng" }`.
2. **Validate (Zod) & Normalize:** Middleware `zValidator` chặn lại, lọc sạch dữ liệu lạ (chống Mass Assignment), `trim` khoảng trắng và convert kiểu dữ liệu.
3. **Controller:** `UsersController.updateMe` nhận clean body, đọc `userId` từ JWT payload, gửi xuống service.
4. **Service:** `UsersService.updateProfile` thực thi nghiệp vụ domain và gọi Repository.
5. **Repository:** `DrizzleUserRepository.save` thực thi SQL ghi nhận an toàn xuống PostgreSQL database.
6. **Response:** Controller nhận response DTO, bọc gói trong `{ data }` và gửi trả Client.

---

## 4. BEST PRACTICES

- **Controller là Clean Boundary:** Controllers tuyệt đối không được truy cập trực tiếp database client (`db`), không được import Drizzle schemas, và không được thay đổi nghiệp vụ logic. Controllers chỉ làm nhiệm vụ parse HTTP metadata và gửi trả HTTP status code.
- **Cookies Security:** Refresh token luôn đi kèm thuộc tính `SameSite=Strict` và `Path=/api/v1/auth`. Điều này giới hạn token không bao giờ bị lộ ở các module khác, tối ưu tính cô lập bảo mật.
- **Strict DTO Mapping:** Sử dụng `c.req.valid('json')` của Hono để đảm bảo dữ liệu truyền qua Controller là an toàn.

## 5. KHẢ NĂNG MỞ RỘNG (FUTURE ENHANCEMENTS)

- **MFA Challenge handler:** Khi cấu hình đăng nhập yêu cầu bảo mật 2 lớp (MFA), Controller có thể đọc trạng thái từ Service và trả về HTTP `200` kèm payload `"status": "awaiting_mfa"` để UI chuyển hướng sang màn hình nhập OTP mà không làm thay đổi luồng API login chính.
