## 1. ENVIRONMENT STRATEGY

---

### 1.1 Mục tiêu

- **Không bao giờ** để secret lọt vào source code hoặc git history
- **Fail fast** khi khởi động: nếu thiếu bất kỳ biến môi trường bắt buộc nào → server từ chối khởi động ngay lập tức, không âm thầm dùng giá trị sai
- **Type-safe** toàn bộ: mọi nơi trong codebase dùng config đều được TypeScript kiểm tra tại compile-time
- **Dễ onboard:** Developer mới chỉ cần copy `.env.example` → điền giá trị → chạy được

---

### 1.2 Thiết kế — Environment Files

#### Phân tầng môi trường

```
.env.example          ← Template (commit vào git) — chứa tất cả keys, không có values thật
.env                  ← Local development (KHÔNG commit — trong .gitignore)
.env.test             ← Test environment (KHÔNG commit — trong .gitignore)
.env.staging          ← Staging (KHÔNG commit — quản lý qua Secret Manager)
.env.production       ← Production (KHÔNG commit — quản lý qua Secret Manager)
```

### 1.3 Thiết kế — Zod Env Schema

#### `src/config/env.ts`

```typescript
import { z } from 'zod'

// ─── Helper ──────────────────────────────────────────────────────────────────

const positiveInt = () => z.coerce.number().int().positive()
const nonEmptyStr = () => z.string().min(1)

// ─── Schema ──────────────────────────────────────────────────────────────────

const envSchema = z.object({
  // Server
  NODE_ENV: z.enum(['development', 'test', 'staging', 'production']),
  PORT: positiveInt().default(3001),
  HOST: nonEmptyStr().default('0.0.0.0'),
  API_VERSION: nonEmptyStr().default('v1'),
  CORS_ORIGINS: z.string().transform((s) => s.split(',')),

  // Database
  DATABASE_URL: z.string().url(),
  DATABASE_POOL_MIN: positiveInt().default(2),
  DATABASE_POOL_MAX: positiveInt().default(10),
  DATABASE_IDLE_TIMEOUT_MS: positiveInt().default(30_000),
  DATABASE_CONNECT_TIMEOUT_MS: positiveInt().default(5_000),

  // Redis
  REDIS_URL: z.string().url(),
  REDIS_KEY_PREFIX: nonEmptyStr().default('hsp:'),
  REDIS_DEFAULT_TTL_SECONDS: positiveInt().default(3600),

  // JWT
  JWT_ACCESS_SECRET: z.string().min(64, 'JWT_ACCESS_SECRET must be at least 64 characters'),
  JWT_REFRESH_SECRET: z.string().min(64, 'JWT_REFRESH_SECRET must be at least 64 characters'),
  JWT_ACCESS_EXPIRES_IN: nonEmptyStr().default('15m'),
  JWT_REFRESH_EXPIRES_IN: nonEmptyStr().default('30d'),

  // Rate Limiting
  RATE_LIMIT_WINDOW_MS: positiveInt().default(60_000),
  RATE_LIMIT_ANON_MAX: positiveInt().default(60),
  RATE_LIMIT_AUTH_MAX: positiveInt().default(300),

  // Logging
  LOG_LEVEL: z
    .enum(['trace', 'debug', 'info', 'warn', 'error', 'fatal'])
    .default('info'),
  LOG_PRETTY: z
    .string()
    .transform((v) => v === 'true')
    .default('false'),

  // Typesense
  TYPESENSE_HOST: nonEmptyStr().default('localhost'),
  TYPESENSE_PORT: positiveInt().default(8108),
  TYPESENSE_PROTOCOL: z.enum(['http', 'https']).default('http'),
  TYPESENSE_API_KEY: nonEmptyStr(),
})

// ─── Parse + Validate ─────────────────────────────────────────────────────────

const _parsed = envSchema.safeParse(process.env)

if (!_parsed.success) {
  console.error('❌ Invalid environment variables:')
  console.error(
    JSON.stringify(
      _parsed.error.flatten().fieldErrors,
      null,
      2
    )
  )
  // Fail fast — không để server chạy với config sai
  process.exit(1)
}

export const env = _parsed.data

// ─── Derived helpers ─────────────────────────────────────────────────────────

export const isDev = env.NODE_ENV === 'development'
export const isTest = env.NODE_ENV === 'test'
export const isProd = env.NODE_ENV === 'production'
export const isStaging = env.NODE_ENV === 'staging'
```

### 1.4 Thiết kế — App Config

#### `src/config/app.config.ts`

Constants không phải secret — hard-coded nhưng có thể override:

```typescript
import { env } from './env'

export const AppConfig = {
  server: {
    port: env.PORT,
    host: env.HOST,
    apiPrefix: `/api/${env.API_VERSION}`,
  },

  pagination: {
    defaultPageSize: 20,
    maxPageSize: 50,
  },

  upload: {
    maxFileSizeBytes: 10 * 1024 * 1024, // 10MB
    allowedMimeTypes: ['image/jpeg', 'image/png', 'image/webp', 'image/avif'],
  },

  auth: {
    bcryptRounds: 12,
    maxActiveSessions: 5,            // Tối đa 5 thiết bị đăng nhập cùng lúc
    refreshTokenRotation: true,      // Rotate refresh token mỗi lần dùng
  },

  cache: {
    // TTL seconds cho từng loại data
    region: 60 * 60 * 24,           // 24h — ít thay đổi
    business: 60 * 15,              // 15m — thay đổi vừa
    article: 60 * 60,               // 1h
    search: 60 * 5,                 // 5m
    healthCheck: 10,                // 10s
  },

  rateLimit: {
    windowMs: env.RATE_LIMIT_WINDOW_MS,
    anon: env.RATE_LIMIT_ANON_MAX,
    auth: env.RATE_LIMIT_AUTH_MAX,
    // Các endpoint đặc biệt
    login: 10,                      // 10 lần/phút cho login (chống brute force)
    passwordReset: 5,               // 5 lần/phút
  },
} as const

export type AppConfig = typeof AppConfig
```

### 1.5 Lý do lựa chọn

| Quyết định | Lý do |
|:---|:---|
| **Zod** cho env validation | Đã dùng Zod cho API validation → nhất quán, không thêm dependency |
| **Fail fast** với `process.exit(1)` | Server chạy với config sai gây bug âm thầm nguy hiểm hơn crash rõ ràng |
| **`env.ts` export const** | Immutable, type-safe, IDE autocomplete — tốt hơn `process.env.X` (string | undefined) rải rác |
| **`app.config.ts` tách riêng** | Phân biệt rõ: secrets (từ env) vs. business constants (hard-coded) |
| **CORS_ORIGINS là string comma-separated** | Dễ set trong Docker/k8s env vars, transform thành array khi parse |
| **Min 64 chars cho JWT secrets** | OWASP khuyến nghị HS256 key >= 256 bits = 32 bytes. 64 hex chars = 32 bytes |

---

### 1.6 Ưu điểm

- **Zero runtime errors** từ missing env vars — server crash đẹp khi start, không crash lúc serving request
- **Full IntelliSense:** `env.DATABASE_URL` thay vì `process.env.DATABASE_URL as string`
- **Single source of truth** cho tất cả config: một file, một chỗ, không rải rác
- **Dễ audit security:** Review một file `env.ts` là biết hết những gì ứng dụng cần

---

### 1.7 Nhược điểm

- **Reload cần restart:** Thay đổi env var cần restart server (không hot-reload được) — chấp nhận được vì đây là thiết kế phổ biến
- **Schema maintenance:** Thêm env var mới phải cập nhật cả `envSchema` lẫn `.env.example`

---

### 1.8 Các lựa chọn khác đã xem xét

| Giải pháp | Vấn đề |
|:---|:---|
| `dotenv` thuần + `process.env.X` | Không type-safe, không validate, thiếu field chỉ biết lúc runtime |
| `t3-env` | Tốt nhưng thêm dependency không cần thiết khi đã có Zod |
| `convict` | API phức tạp hơn Zod, ít phổ biến trong Bun ecosystem |
| AWS Parameter Store / Vault | Overkill cho Phase 2, phức tạp hóa local dev |

---

### 1.9 Vì sao không chọn

- **`process.env.X` thuần:** TypeScript không kiểm tra được. Developer có thể dùng `process.env.DATABSE_URL` (typo) và chỉ phát hiện khi runtime.
- **`t3-env`:** Thêm dependency trong khi Zod đã đủ mạnh. Nguyên tắc: không thêm dependency nếu không có lý do rõ ràng.

---

### 1.11 Security Considerations

```
✅ JWT secrets minimum 64 chars (256-bit security)
✅ Không bao giờ log giá trị secret (Pino serializer sẽ redact)
✅ .env trong .gitignore — kiểm tra bằng pre-commit hook
✅ .env.example chứa placeholder "CHANGE_ME_*" — tránh copy-paste nhầm
✅ process.exit(1) khi validation fail — không serve với config sai
```

---

### 1.12 Best Practices

- **Đặt tên biến:** `SCREAMING_SNAKE_CASE` cho env vars (POSIX standard)
- **Group bằng comment:** Phân nhóm rõ trong `.env.example` — Server / Database / Redis / JWT...
- **Default values:** Chỉ set default cho non-critical config — secret không được có default
- **Prefix `CHANGE_ME_`:** Mọi placeholder secret phải có prefix này để grep ra dễ
- **Audit log:** Khi app start, log ra danh sách env vars đã load (KHÔNG log values — chỉ log keys)
