## 1. MỤC TIÊU

Thiết kế chi tiết tầng truy xuất dữ liệu (Repository Layer) tinh giản cho **Identity Module** nhằm:
- Hiện thực hóa các giao diện trừu tượng `IUserRepository` và `ISessionRepository` bằng công cụ Drizzle ORM kết nối PostgreSQL thuần túy, loại bỏ hoàn toàn Redis caching theo định hướng tối giản MVP.
- Thiết lập cơ chế ánh xạ dữ liệu (Data Mapping) hai chiều giữa Database Schema (Drizzle Data Model) và Domain Layer (Entities/Aggregates) để bảo toàn tính độc lập của Domain.
- Sử dụng giao dịch PostgreSQL (Transactions) tại Drizzle level để đảm bảo tính nhất quán của dữ liệu khi ghi nhận nhiều bảng liên kết (users + profiles).
- Hỗ trợ Soft Delete cho thực thể người dùng (`deleted_at`).

### 2.1 Domain Data Mappers

Sử dụng Mapper để chuyển đổi dữ liệu từ Drizzle DB query sang Rich Domain Entities và ngược lại.

#### 1. User Mapper: `apps/backend/src/modules/users/mapper/user.mapper.ts`
```typescript
import { User } from '../domain/user.aggregate'
import { UserProfile } from '../domain/profile.entity'
import { Email } from '../domain/value-objects/email.vo'
import { Password } from '../domain/value-objects/password.vo'

export class UserMapper {
  public static toDomain(rawDbUser: any, rawDbProfile: any): User {
    const profile = new UserProfile(
      rawDbProfile.id,
      rawDbProfile.userId,
      rawDbProfile.firstName,
      rawDbProfile.lastName,
      rawDbProfile.avatarUrl,
      rawDbProfile.phoneNumber,
      rawDbProfile.bio
    )

    return new User(
      rawDbUser.id,
      new Email(rawDbUser.email),
      new Password(rawDbUser.passwordHash),
      [], // Tạm thời bỏ PasswordHistory cho MVP
      rawDbUser.role,
      rawDbUser.status,
      rawDbUser.failedLoginAttempts,
      rawDbUser.lockoutUntil ? new Date(rawDbUser.lockoutUntil) : null,
      rawDbUser.permissionsVersion,
      {
        createdAt: new Date(rawDbUser.createdAt),
        updatedAt: new Date(rawDbUser.updatedAt),
        lastLoginAt: rawDbUser.lastLoginAt ? new Date(rawDbUser.lastLoginAt) : null,
        lastPasswordChangedAt: rawDbUser.lastPasswordChangedAt ? new Date(rawDbUser.lastPasswordChangedAt) : null,
        lastFailedLoginAt: rawDbUser.lastFailedLoginAt ? new Date(rawDbUser.lastFailedLoginAt) : null,
      },
      profile
    )
  }

  public static toPersistence(user: User) {
    return {
      userTableData: {
        id: user.id,
        email: user.email.getValue(),
        passwordHash: user.password.getHash(),
        role: user.role,
        status: user.status,
        failedLoginAttempts: user.failedLoginAttempts,
        lockoutUntil: user.lockoutUntil,
        permissionsVersion: user.permissionsVersion,
        createdAt: user.createdAt,
        updatedAt: user.updatedAt,
        lastLoginAt: user.lastLoginAt,
        lastPasswordChangedAt: user.lastPasswordChangedAt,
        lastFailedLoginAt: user.lastFailedLoginAt,
      },
      profileTableData: {
        id: user.profile.id,
        userId: user.profile.userId,
        firstName: user.profile.firstName,
        lastName: user.profile.lastName,
        avatarUrl: user.profile.avatarUrl,
        phoneNumber: user.profile.phoneNumber,
        bio: user.profile.bio,
      }
    }
  }
}
```

### 2.2 Drizzle Repositories Implementation

#### 1. `DrizzleUserRepository`: `apps/backend/src/modules/users/repository/users.repository.ts`

```typescript
import { IUserRepository } from './user-repository.interface'
import { User } from '../domain/user.aggregate'
import { db } from '@/lib/database/client'
import { users, userProfiles } from '@/lib/database/schema'
import { eq, and, isNull } from 'drizzle-orm'
import { UserMapper } from '../mapper/user.mapper'

export class DrizzleUserRepository implements IUserRepository {
  
  public async findById(id: string): Promise<User | null> {
    // Đọc trực tiếp PostgreSQL (đã JOIN) kèm soft delete filter
    const dbResult = await db
      .select()
      .from(users)
      .innerJoin(userProfiles, eq(users.id, userProfiles.userId))
      .where(
        and(
          eq(users.id, id),
          isNull(users.deletedAt) // Soft Delete Filter
        )
      )
      .limit(1)

    if (dbResult.length === 0) return null
    const { users: rawUser, user_profiles: rawProfile } = dbResult[0]

    return UserMapper.toDomain(rawUser, rawProfile)
  }

  public async findByEmail(email: string): Promise<User | null> {
    const dbResult = await db
      .select()
      .from(users)
      .innerJoin(userProfiles, eq(users.id, userProfiles.userId))
      .where(
        and(
          eq(users.email, email.toLowerCase().trim()),
          isNull(users.deletedAt)
        )
      )
      .limit(1)

    if (dbResult.length === 0) return null
    const { users: rawUser, user_profiles: rawProfile } = dbResult[0]

    return UserMapper.toDomain(rawUser, rawProfile)
  }

  public async save(user: User): Promise<void> {
    const { userTableData, profileTableData } = UserMapper.toPersistence(user)

    // Sử dụng transaction nguyên thủy
    await db.transaction(async (tx) => {
      // Upsert User
      await tx
        .insert(users)
        .values(userTableData)
        .onConflictDoUpdate({
          target: users.id,
          set: userTableData,
        })

      // Upsert Profile
      await tx
        .insert(userProfiles)
        .values(profileTableData)
        .onConflictDoUpdate({
          target: userProfiles.id,
          set: profileTableData,
        })
    })
  }
}
```

#### 2. `DrizzleSessionRepository`: `apps/backend/src/modules/auth/repository/session.repository.ts`

```typescript
import { ISessionRepository } from './session-repository.interface'
import { UserSession } from '../domain/session.entity'
import { db } from '@/lib/database/client'
import { userSessions } from '@/lib/database/schema'
import { eq, and } from 'drizzle-orm'
import { ClientFingerprint } from '../domain/value-objects/fingerprint.vo'

export class DrizzleSessionRepository implements ISessionRepository {

  public async findById(id: string): Promise<UserSession | null> {
    const [rawSession] = await db
      .select()
      .from(userSessions)
      .where(eq(userSessions.id, id))
      .limit(1)

    return rawSession ? this.toDomain(rawSession) : null
  }

  public async findByTokenHash(tokenHash: string): Promise<UserSession | null> {
    const [rawSession] = await db
      .select()
      .from(userSessions)
      .where(
        and(
          eq(userSessions.tokenHash, tokenHash), 
          eq(userSessions.isRevoked, false)
        )
      )
      .limit(1)

    return rawSession ? this.toDomain(rawSession) : null
  }

  public async save(session: UserSession): Promise<void> {
    const data = {
      id: session.id,
      userId: session.userId,
      tokenHash: session.tokenHash,
      deviceId: session.fingerprint.deviceId,
      ipAddress: session.fingerprint.ipAddress,
      userAgent: session.fingerprint.userAgent,
      expiresAt: session.expiresAt,
      isRevoked: session.isRevoked,
      updatedAt: new Date(),
    }

    await db
      .insert(userSessions)
      .values(data)
      .onConflictDoUpdate({
        target: userSessions.id,
        set: data,
      })
  }

  public async getActiveSessionsCount(userId: string): Promise<number> {
    const result = await db
      .select()
      .from(userSessions)
      .where(
        and(
          eq(userSessions.userId, userId), 
          eq(userSessions.isRevoked, false)
        )
      )

    return result.length;
  }

  public async revokeSession(id: string): Promise<void> {
    // Đăng xuất đơn giản
    await db
      .update(userSessions)
      .set({ isRevoked: true, updatedAt: new Date() })
      .where(eq(userSessions.id, id))
  }

  private toDomain(raw: any): UserSession {
    return new UserSession(
      raw.id,
      raw.userId,
      raw.tokenHash,
      new ClientFingerprint(raw.deviceId, raw.ipAddress, raw.userAgent),
      new Date(raw.expiresAt),
      raw.isRevoked
    )
  }
}
```

## 3. DEPENDENCY & LUỒNG DỮ LIỆU

```
UsersService ──> IUserRepository (Interface)
                        ▲
                        │ (Implements)
              DrizzleUserRepository ──> Drizzle DB Client ──> PostgreSQL
```

- Không dùng Redis Cache ở giai đoạn này.
- Luồng dữ liệu chạy thẳng xuống PostgreSQL để đảm bảo tính đơn giản và dễ vận hành.

---

## 4. BEST PRACTICES

- **SQL JOINs for Aggregates:** Khi nạp User Aggregate, luôn JOIN bảng `user_profiles` để nạp đủ trạng thái của Aggregate trong 1 truy vấn.
- **Transaction Scope:** Bọc các tác vụ ghi đa bảng (User + Profile) vào một transaction để tránh dữ liệu mồ côi nếu có lỗi phát sinh giữa chừng.
- **Soft Delete handling:** Luôn đưa điều kiện `isNull(users.deletedAt)` vào các API lấy thông tin người dùng.

---

## 5. KHẢ NĂNG MỞ RỘNG (FUTURE ENHANCEMENTS)

- **Redis Cache-Aside:** Khi quy mô người dùng tăng lên (Phase 7+), ta dễ dàng cắm Redis client vào `DrizzleUserRepository.findById` để cache JSON của User, hoàn toàn không sửa đổi service logic.
- **FIFO Session Eviction:** Có thể dễ dàng thêm lệnh xoay vòng session cũ trong hàm `save()` của Repository nếu số lượng thiết bị hoạt động vượt hạn mức.
