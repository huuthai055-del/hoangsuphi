## 5. MIGRATION PRODUCTION ROLLOUT STRATEGY

> [!WARNING]
> Việc chạy trực tiếp migration chứa lệnh `CREATE INDEX` chuẩn trong transaction block có thể gây Lock toàn bộ hoạt động GHI trên bảng đối với dữ liệu Production dưới traffic cao.

### 5.1 Rollout Plan trên môi trường Production
Để không gây gián đoạn dịch vụ, quy trình triển khai index trên môi trường production sẽ được thực hiện thủ công hoặc thông qua công cụ chuyên dụng (không dùng Drizzle Kit tự động trên live database):

1.  **Chạy ngoài Transaction block:** Index phải được xây dựng bằng từ khóa `CONCURRENTLY`.
2.  **Lệnh SQL thực thi tuần tự:**
    ```sql
    CREATE INDEX CONCURRENTLY IF NOT EXISTS "tourist_places_location_gist_idx" ON "tourist_places" USING gist ("location");
    CREATE INDEX CONCURRENTLY IF NOT EXISTS "businesses_location_gist_idx" ON "businesses" USING gist ("location");
    ```
3.  **Xử lý lỗi invalid index:** Xây dựng index concurrently có thể thất bại nếu có transaction xung đột dài hạn. Nếu truy vấn `indisvalid` trả về `false`, cần chạy lệnh:
    ```sql
    DROP INDEX CONCURRENTLY IF EXISTS "tourist_places_location_gist_idx";
    -- Sau đó thực hiện build lại
    ```
