## Scope delivered

- Public, read-only `GET /api/v1/recommendations`.
- Four SQL/PostgreSQL/PostGIS strategies: `nearby`, `same_region`, `top_rated`, and `newest`.
- No Redis cache, AI recommendation, queue, analytics/history write, migration, or frontend work.
- One database query for global strategies; public-source lookup plus one candidate query for source-based strategies. No N+1 query pattern.

## Public contract

- Query parameters: `strategy`, `sourceType`, `sourceId`, `limit`.
- Success response: `{ "data": [...], "meta": {...}, "error": null }`.
- Cache policy: `Cache-Control: no-store`.
- Invalid or unavailable sources return the generic RFC 7807 response `RECOMMENDATION_SOURCE_NOT_FOUND_OR_UNAVAILABLE`.

- Query DTO rejects unknown, repeated, malformed, and invalid strategy/source parameters.
- Repository uses parameter-bound SQL and wraps database failures without exposing raw database messages.
- Repository is read-only; no write statement, migration, or new database object is introduced.
