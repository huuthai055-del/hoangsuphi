## 4. BEST PRACTICES CHO GIAI ĐOẠN LẬP TRÌNH (EXECUTION RULES)

1. **Auto Path Generation:** Tuyệt đối không cho phép client thay đổi hoặc gửi trực tiếp `path` ltree lên API. `path` phải được Backend tự tạo bằng cách nối ltree path của nút cha (`parentId`) với slug của chính nó.
2. **Kinh độ trước, Vĩ độ sau:** Chuẩn tọa độ GPS trao đổi qua JSON/DB luôn là `POINT(lng lat)` (Kinh độ viết trước, Vĩ độ viết sau).
3. **Database Test Rollback:** Integration tests cho PostGIS queries bắt buộc phải chạy rollback transaction ở cuối mỗi test để làm sạch DB test.
